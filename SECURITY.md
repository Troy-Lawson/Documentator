# Security policy

## Supported versions

Documentator is currently an experimental prototype. No version is supported
for production use yet.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature for this repository. If that feature
is unavailable, contact the repository owner privately through their GitHub
profile and provide only enough information to arrange a secure report.

Do not include real credentials, private instance URLs, customer data, or
internal operational information in reports or reproductions.
